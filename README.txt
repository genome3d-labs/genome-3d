GENOME SITE V4 — BILÍNGUE

Novidade principal:
- Botão de idioma no cabeçalho.
- Alternância instantânea entre Português e English.
- A escolha fica salva no navegador.
- Ao entrar na página de Login, o idioma escolhido é mantido.
- A página de Login também foi traduzida.

Como testar:
1. Extraia o ZIP.
2. Abra index.html.
3. Clique no botão "English" no centro do cabeçalho.
4. O site muda para inglês e o botão passa a mostrar "Português".
5. Clique em Login: a página de login mantém o mesmo idioma.
6. Se fechar e abrir o site novamente no mesmo navegador, a escolha anterior continua salva.
